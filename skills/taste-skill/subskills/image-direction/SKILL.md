# Image direction

1. Name what the reader should discover in this section. Look at the available files before choosing a layout. Write the visible subject, its position, the calm space and its job in one line per photograph. Keep a catalogue grid when equal views help a buyer compare. Use a real project view to identify a project. Use stand-ins for clearly identified references, atmosphere or material. If the available file shows the wrong thing, let words, a plan or a measured drawing carry the section.
2. Pick one leading view. A three-frame spread can use a room to establish scale, a surface to show the finish and a junction to explain construction. Repeat the arrangement only for a new question. Vary distance and silhouette. An arch can echo an opening, a circle can isolate a round detail, a wide strip can trace a ridge. Clip one wrapper with `border-radius: 50%` for a circle or round just its top corners for an arch. Keep the other frames quiet.
3. Sketch the large and small frames together with the heading and any factual label. Align one edge to the page grid. Let an inset cross a quiet corner or section edge only where the connection between frames matters. Test any overlaid type against the cropped pixels. A promise about a joint needs the joint to be visible. Use a reserved grid cell and a small negative block margin for a crossing. Keep the inset clear of the main subject. Use a full-bleed photograph as the section ground when it can carry the whole scene. Find the most even patch in the actual crop, try dark or light live type there and inspect the whole glyph area at both widths. Move the heading onto the page ground if the light crosses it. Where identification helps, put one permitted fact line near the frame.
4. Use the page’s grid, spacing, ink, surface, radius and type tokens. Working alone, take these from the existing project. Use CSS on plain `<img>` elements in ratio-reserved boxes. Set intrinsic width and height, `object-fit: cover` and an intentional `object-position`. For a tint, give the wrapper an accent ground and lower image opacity slightly. A stronger duotone can use grayscale and luminosity blending on that ground. Preserve material colour when that colour is evidence. Never treat cropping as permission to invent a subject.
5. At phone width choose the focal point and order again. Keep fact lines attached, constrain the overlap or release it, and retain the difference between lead and detail. Recompose a strip and an inset as a stepped pair if shrinking them into a row makes them look alike. The complete sequence remains visible without script. Any optional motion is limited to transform or opacity on the kit’s `--dur` and `--ease`. Keep the still under reduced motion.

**Reject** three equal tiles saying the same thing, a mask cutting a subject in two, an inset covering the reason for the main picture, white type over bright texture and a stock interior presented as completed work.

**Deliver** a figure or section with scoped CSS and local images. Give informative frames concise alt text about the visible subject and use empty alt for a decorative repeat. Keep text assets below 60 KB. The studio layout in `example/` includes the shot brief, local path and ready-to-use `<img>` for each slot.

**Check** with `node check.mjs path/to/index.html` for local paths, alt attributes and intrinsic dimensions. It compares WebP and PNG dimensions to the file. At 1440 and 390, inspect the subject, focal edge, order, text contrast and every overlap. Hide the photos once and verify the boxes and heading hold their positions. Cover each support in turn. Remove a frame if its absence makes no difference.
