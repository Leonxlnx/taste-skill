Effect components
Effects library

Effects as parts of the page, not only behind it

Feature cards, real objects drawn in dither, type, numbers, buttons, borders, icons, a street map of the real place, a globe, charts and a photograph in its own colours. Every part takes its colours from the page palette: switch it at the top right. Parts that loop have a pause button.

Each component is a folder in assets/components with its markup, CSS, script and a meta.json that says what it is for and which effects suit it. Use one strong effect moment per page; the rest stay quiet. _lab.html?c=fx-chart&fx=ruled-grounds&palette=white-link-blue shows one part with another effect.
