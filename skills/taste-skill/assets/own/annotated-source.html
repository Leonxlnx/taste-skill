How the packing label is counted

Elm Parcel packs six items to a box. The label prints the item count, box count and remaining space.

label.py
12345
def label(items):
    count = sum(items)
    boxes = (count + 5) // 6
    spare = boxes * 6 - count
    return count, boxes, spare
