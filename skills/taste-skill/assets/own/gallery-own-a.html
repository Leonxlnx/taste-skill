How the packing label is counted

Elm Parcel packs six items to a box. The label prints the item count, box count and remaining space.

label.py
12345
def label(items):
    count = sum(items)
    boxes = (count + 5) // 6
    spare = boxes * 6 - count
    return count, boxes, spare
ABC

Run with three entries

count, boxes, spare = label([4, 5, 2])
print(f"{count} items, {boxes} boxes, {spare} spare place")
