Read a rain gauge sample

Use an installed runtime to read a station measurement from Silt Meter.

Before you run

Install Python 3, Node or Ruby. Save this sample as reading.json.

{"station":"S4","mm":12}

Run from the directory containing both files.

Python 3

Source · read.py
import json
print(json.load(open("reading.json"))["mm"])
Run command
python read.py
Expected output12

Node

Source · read.cjs
const fs = require("node:fs");
console.log(JSON.parse(fs.readFileSync("reading.json","utf8")).mm);
Run command
node read.cjs
Expected output12

Ruby

Source · read.rb
require "json"
puts JSON.parse(File.read("reading.json"))["mm"]
Run command
ruby read.rb
Expected output12
