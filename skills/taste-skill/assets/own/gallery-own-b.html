Read a rain gauge sample

Use an installed runtime to read a station measurement from Silt Meter.

Before you run

Install Python 3, Node or Ruby. Save this sample as reading.json.

{"station":"S4","mm":12}

Run from the directory containing both files.

Python 3

Source · read.py
import json
print(json.load(open("reading.json"))["mm"])
Run command
python read.py
Expected output12

Node

Source · read.cjs
const fs = require("node:fs");
console.log(JSON.parse(fs.readFileSync("reading.json","utf8")).mm);
Run command
node read.cjs
Expected output12

Ruby

Source · read.rb
require "json"
puts JSON.parse(File.read("reading.json"))["mm"]
Run command
ruby read.rb
Expected output12

Weave a 40 cm sampler

A three-chapter field guide from Mere Loom.

Sampler guide
ThreadingWeavingFinishing
Threading chart

Threading

Thread 80 ends across 40 cm, at 2 ends per cm. Work from left to right, alternating one heddle slot and one hole.

Weaving

Weave 60 picks. Pass the shuttle through the shed for each pick, alternating its direction across the warp.

Finishing

Fold and stitch a 2 cm hem at each end of the sampler.

The footbridge reopens

12 Nov · Wick Valley Field Notes

The crossing at Mill Beck is open again. The new deck follows the old footbridge between the orchard bank and the meadow. Walkers can use the crossing from either bank.

Back to the footbridge reopens

Orchard gate moved

9 Nov · Wick Valley Field Notes

The entrance on the west side of the orchard has moved. From the lane, follow the hedge to the new opening. Close the gate behind you. Visitors collecting mugs at the lane entrance can check Reeve Ceramics collection hours.

Back to orchard gate moved

Two winter paths

4 Nov · Wick Valley Field Notes

Both paths across the upper meadow remain open for winter. One follows the hedge and the other cuts across to the ridge. Use either route on the way back from the beck.

Back to two winter paths

Ferry hours change

28 Oct · Wick Valley Field Notes

The valley ferry is on its winter timetable. The final boat leaves at 16:30. Arrive at the landing before that departure to cross the beck.
