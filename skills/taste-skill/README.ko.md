# tasteskill v2 (`design-taste-frontend`)

코딩 에이전트를 위한 디자인 스킬입니다. 2026년 10월 One Page Love와 Awwwards Sites of the Day에 소개된 엄선된 사이트 247개를 연구해 만들었습니다. 에이전트가 흔한 랜딩 페이지 구성에 의존하지 않도록 아트 디렉션을 제공하고, 불필요한 장식을 배제하는 엄격한 이 스킬의 디자인 원칙을 적용합니다. 또한 작업을 마쳤다고 보고하기 전에 직접 렌더링 결과를 살펴보게 합니다.

## 작동 방식

1. **고유한 소재 정리.** 에이전트가 이 클라이언트만의 소재를 정리합니다. 이름과 그 의미, 거리, 수치, 핵심 제약 조건, 재료, 운영 시간 등이 여기에 해당합니다.
2. **디자인 방향 후보 제안.** `scripts/draw.mjs`가 20가지 디자인 방향 중 3가지를 무작위로 골라 제시합니다. 각 방향은 연구 대상 중 뛰어난 사이트에서 발견한 아이디어 발상 방식입니다. 에이전트가 앞서 정리한 소재를 살릴 수 있는 방향을 고르면, 스크립트가 나머지를 제시합니다. 히어로 영역(첫 화면의 핵심 영역) 구성, 섹션 구성, 실제 무료 글꼴로 이루어진 타이포그래피 체계, 팔레트, 사진, 모션, 연구한 레퍼런스가 포함됩니다. 각 구성안 아래에는 이 스킬의 디자인 원칙과 충돌하는 항목도 표시합니다. 최근 제안한 후보를 기억해 프로젝트마다 같은 구성이 반복되지 않게 합니다.
3. **핵심 아이디어와 방문자가 할 수 있는 행동.** 클라이언트 고유의 소재와 선택한 방향의 표현 방식을 연결하는 문장을 하나 작성하고, 가장 유사한 경쟁사와 비교합니다. 방문자가 페이지에서 실제로 할 수 있는 행동도 하나 정합니다.
4. **구현.** 제시된 설계안을 바탕으로 문구부터 작성하고, 전체 콘텐츠를 빠짐없이 구현합니다. 프로젝트에 자체 사진이 없으면 `scripts/assets.mjs`가 공개 컬렉션에서 주제와 관련된 실제 이미지를 찾습니다. 옛 엽서에 담긴 해당 거리, 오래된 지도, 관련 재료, 해당 업종을 묘사한 판화, 같은 종류의 박물관 소장품 등이 그 예입니다. 이미지를 프로젝트에 다운로드하고 출처를 기록합니다. 주제를 제대로 보여줄 실제 이미지가 없을 때만 코드로 그립니다.
5. **품질 검사.** `scripts/lint.mjs`는 소스를, `scripts/inspect.mjs`는 실제 브라우저 화면을 1440 / 768 / 390 너비에서 검사합니다. 이 스킬의 디자인 원칙은 다음과 같습니다. 제목은 두 줄 이내로 작성하고, 제목 위의 작은 보조 라벨, 고정폭 글꼴, 01/02/03식 번호, 가는 구분선, 그라데이션, 기본 상태의 그림자, 크림색과 테라코타색 조합, 보라색을 사용하지 않습니다. 블라인드 평가에서 감점된 결함도 검사합니다. 시선이 모이는 중심 요소가 없는 화면, 비어 있는 화면, 가려지거나 잘린 텍스트, 지나치게 긴 스크롤 고정 구간, 가로 스크롤이 필요한 행, 흐릿한 텍스트 등이 여기에 해당합니다.
6. **화면 검토.** 검사 도구가 스크린샷을 저장하면, 에이전트가 Awwwards의 평가 가중치를 반영한 기준표로 검토합니다. 가장 큰 문제 세 가지를 수정하고 다시 확인하는 과정을 최대 세 차례 반복합니다.

스킬을 사용하지 않은 기준 결과 및 다른 디자인 스킬과 비교한 다섯 차례의 블라인드 테스트는 `references/research.md` §11에 기록되어 있습니다.

## 구성

```text
SKILL.md                 작업 절차, 이 스킬의 디자인 원칙, 기본 원칙
references/              문구, 타이포그래피, 색상, 레이아웃, 이미지, 모션, 비평,
                         상투적인 표현의 징후, 연구 자료
scripts/draw.mjs         후보 제시 / 방향 선택 / 결과 재출력 / 후보 재생성;
                         --alternatives, --photos, --site
scripts/assets.mjs       공개 이미지 컬렉션(Openverse, Wikimedia Commons,
                         Art Institute of Chicago, the Met) 검색;
                         --video로 실제 영상(Wikimedia Commons, Internet Archive,
                         NASA) 검색; --get으로 출처 정보와 함께 다운로드,
                         --credits로 출처 정보 출력
scripts/lint.mjs         금지된 패턴과 상투적인 문구 정적 검사
scripts/inspect.mjs      렌더링, 측정, 화면 촬영
scripts/lib/             외부 의존성 없는 Chrome DevTools 클라이언트,
                         페이지 내부 검사 코드, 검사 규칙
library/                 디자인 방향(20개), 히어로 영역, 섹션, 타이포그래피 체계,
                         팔레트, 사진, 연구 대상 사이트, 모션
assets/base.css, base.js 선택적으로 사용하는 중립적인 기본 스타일과 스크립트
evals/evals.json         스킬을 사용하지 않은 기준 결과와 비교하기 위한
                         테스트 브리프(작업 요구서) 6개
```

## 요구 사항

`inspect.mjs`를 사용하려면 Node 22 이상과 Chrome, Edge 또는 Chromium이 설치되어 있어야 합니다. Node에 내장된 WebSocket으로 DevTools 프로토콜을 통해 브라우저를 제어하며, 별도의 구성 요소를 설치하지 않습니다. `draw.mjs`, `lint.mjs`, `assets.mjs`는 Node 18 이상에서 실행됩니다. `assets.mjs`에는 네트워크 연결이 필요하지만 API 키는 필요하지 않습니다. 브라우저가 일반적이지 않은 경로에 설치되어 있다면 `CHROME_PATH`를 설정하세요.

## 설치

이 폴더를 `~/.claude/skills/design-taste-frontend/` 같은 스킬 디렉터리에 복사하거나, 저장소의 `.claude/skills/` 아래에 두세요.

## 참고 사항

- 라이브러리에 포함된 사진은 Lorem Picsum이 Unsplash에서 가져와 제공하며, Unsplash 라이선스를 따릅니다. 분위기를 보여주기 위한 임시 이미지이므로 프로젝트의 자체 사진으로 교체하세요.
- `assets.mjs`로 찾은 이미지는 각 이미지의 라이선스를 그대로 따릅니다. 기본적으로 CC0, 퍼블릭 도메인, CC BY, CC BY-SA 이미지만 제시합니다. `--get`은 다운로드한 각 이미지의 제목, 창작자, 라이선스, 출처를 `assets/credits.json`에 기록합니다. 페이지에는 출처 정보를 반드시 표시해야 합니다. `--credits`로 이 정보를 출력할 수 있습니다.
- `assets.mjs --video`는 주제와 관련된 짧은 영상을 찾아 720p 이하 버전을 가져옵니다. `--max-mb`를 지정하지 않으면 25 MB를 초과하는 파일은 받지 않으며, 각 영상과 함께 포스터 프레임도 저장합니다. 페이지에서 사용하는 방법은 `references/imagery.md` §11을 참고하세요. 음소거 반복 재생, 포스터 표시, 모션 줄이기 설정 시 재생 중지에 관한 내용이 포함되어 있습니다.
- 글꼴은 Google Fonts와 Fontshare에서 불러옵니다. 사용하려는 각 글꼴의 라이선스를 확인하세요.
- `references/research.md`의 점수는 스크린샷에 대한 모델의 평가이며, Awwwards가 부여한 점수가 아닙니다.
- 후보 제안 기록은 `~/.taste-skill/history.json`에 저장됩니다. 위치를 바꾸려면 `TASTE_SKILL_HISTORY`를 설정하세요. 기록 파일을 삭제하면 초기화됩니다.
- 화면 검토와 수정 과정을 모두 거치는 구현 작업에는 에이전트 기준으로 약 30–45분과 수십만 토큰이 필요합니다. 프로젝트에 사진이 없다면, 대부분의 작업은 이미지를 찾거나 그리는 데 쓰입니다.
