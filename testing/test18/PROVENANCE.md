# Provenance

## Image

`public/assets/light-installation.png` was generated with OpenAI image generation for this project. Prompt direction: a photorealistic wide editorial photograph of an amber-red linear light installation in a dark concrete gallery, with silhouetted visitors, no text or logos.

## Component

`BouncyAccordion` in `components/bouncy-accordion.tsx` adapts the verified Taste Blocks component `componentry-bouncy-accordion` from `D:/Taste Skill/taste-blocks/public/r/componentry-bouncy-accordion.json` (Componentry by Harsh Jadhav, MIT). It preserves native button semantics, exclusive/collapsible open state, connected-row spring motion, reduced-motion behavior, labelled regions, and inert collapsed content while replacing Tailwind styling with this exhibition’s CSS.
