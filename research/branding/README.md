# Branding research

Research for the TasteSkill V2 branding rules used on landing pages, portfolios, and normal websites.

## Files

- `findings.md` — deduplicated professional findings, examples, font direction, and implementation guidance.
- `sources.md` — primary references, inspected brand sites, open-source design systems, and reuse constraints.
- `../../rules/branding.md` — the executable rules distilled from this research.

## Scope

This research covers brand strategy translation, identity systems, color, typography, font licensing and delivery, logos, grids, photography, illustration, iconography, texture, motion identity, dark mode, accessibility, responsive behavior, and AI-specific failure modes.

It does not provide a universal visual style. TasteSkill must derive a direction from the user's product, audience, content, existing assets, and requested tone.

## Research standard

- Prefer standards, official design systems, official brand guidance, foundries, and upstream font repositories.
- Treat award sites as observation material, not implementation authority.
- Abstract principles from reference sites; never copy their layouts, artwork, copy, marks, paid fonts, or trade dress.
- Treat permissively licensed code separately from trademarked brand assets.
- Label heuristics as heuristics. Do not turn 60/30/10, modular scales, font-pair formulas, or Awwwards trends into universal laws.
