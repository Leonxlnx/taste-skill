# Component Categories

Taste Blocks uses component families only. Website sections and layout blocks belong to the later layout phase and are excluded from this catalog.

| Category | Included component types | Target |
| --- | --- | ---: |

| Visual effects | CSS, SVG, Canvas, WebGL, shaders, masks, particles, fields | 70 |
| Buttons and actions | Buttons, icon actions, copy, share, confirm, action groups | 60 |
| Navigation and menus | Menus, tabs, breadcrumbs, command surfaces, pagination, docks | 55 |
| Media and galleries | Carousels, image effects, viewers, comparisons, video controls | 60 |

## What counts

An entry counts only when it has:

- a materially distinct public component or interaction;
- exact upstream source and immutable revision;
- a compatible license and retained notices;
- copied or minimally adapted working source;
- a live isolated preview;
- explicit dependencies and assets;
- responsive, keyboard, accessibility, and reduced-motion behavior where applicable;
- a unique normalized code and behavior fingerprint;
- verified registry output.

## What does not count

- complete website sections, layouts, page templates, dashboards, or screens;
- color, theme, radius, size, timing, copy, or alignment variants;
- Tailwind and CSS ports of the same component;
- the same component copied from several downstream repositories;
- wrappers around an existing dependency without a distinct component implementation;
- preview fixtures, shared helpers, or catalog-only effects;
- discovered, rejected, broken, or unverified candidates.
