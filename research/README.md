# Research

Background research that informed the skills in this project. Each topic gets its own subfolder.

## Topics

### [Components](components/)
Source policy, catalog categories, block families, effects, motion components, provenance, and site direction for Taste Blocks.

### [Sections](sections/)
The 21 broad page sections used for landing pages, portfolios, and general websites.

### [Animations](animations/)
Motion principles, implementation patterns, libraries, and source research.

### [Copywriting](copywriting/)
AI writing failure modes, useful web copy, UX writing, evidence, voice, and editing.

### [Anti-slop](anti-slop/)
Visual, layout, behavior, and general patterns that make generated websites feel generic or careless.

### [LLM Laziness](laziness/)
Why AI models produce incomplete outputs (placeholder code, truncated responses, skipped sections) and documented techniques to prevent it. Covers root causes, parameter fixes, prompt techniques, and experiment data.
