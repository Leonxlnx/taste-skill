# Security Policy

## Supported Versions

Only the latest stable release of taste-skill is supported with security updates.

## Reporting a Vulnerability

We take the security of taste-skill seriously. If you find a security vulnerability, please do not disclose it publicly. Instead, report it privately by:
1. Submitting a Security Advisory under the **Security** tab of the repository on GitHub.
2. Contacting the team directly via email at **hello@tasteskill.dev**.

Please provide a clear description of the vulnerability, reproduction steps, and potential impact. We will coordinate a resolution and release a security advisory promptly.
